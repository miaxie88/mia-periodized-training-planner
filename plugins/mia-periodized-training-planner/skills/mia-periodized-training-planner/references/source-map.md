# Andy Galpin 周期化课程来源映射

## 来源与边界

本 skill 的主骨架来自用户提供的 Andy Galpin 《25-Minute Physiology》中关于 periodization / program design 的约 35 分钟英文自动转录。

这份资料适合提炼“如何设计计划”的决策框架，但存在两个边界：

1. 自动转录有误，专业词已按上下文校正，不把破碎字句当作逐字引文。
2. 本次工作没有对视频提及的每个训练生理主张做独立文献核查。应将它当作计划方法来源，不是所有具体处方的单一证据。

## 原课直接支持的原则

| 时间段 | 原课主题 | 在 skill 中的用法 |
|---|---|---|
| 00:37–02:44 | 周期化是有意图的计划性变化，不是随机换训练 | 所有变化都要能连回具体适应、减少过用风险或峰值日 |
| 02:43–05:51 | Macrocycle → mesocycle → block → microcycle | 用多层时间结构管理不同尺度的目标 |
| 06:02–12:30 | 传统的通用→特异进程；必须用某种方式渐进超负荷 | 用作运动表现的基础模型，并明确不是每个项目的通则 |
| 12:42–16:34 | 常见峰值模型中训练量下降、强度上升；负荷应有波动 | 只在有峰值需求时使用，不将其写成全人群定律 |
| 16:14–17:19 | GPP 通用身体准备逐渐转向运动特异准备 | 新手和远离比赛时保留更多通用性 |
| 18:08–23:25 | 从大到小：日历、大目标、defenders、小目标、块长与顺序，最后到每天 | 成为本 skill 的主工作流；禁止从第一天的动作清单开始 |
| 23:24–25:39 | 同一“减重”目标，不同基线需要不同路径 | 不按目标名称直接套模板；先看训练年龄、肌力和耐受性 |
| 25:38–30:06 | 集中块、按周波动、按日波动、垂直整合 | 根据是否必须同时保留多项能力选择组织模型 |
| 29:30–30:06 | 一个周期的主适应由最多时间/重点分配决定 | 用资源份额验证口头上的“主目标” |
| 30:04–33:52 | 连续加载后回调；后期低负荷周可高于早期普通周；跨块转换次数/强度 | 用波式负荷代替永远线性加码 |
| 33:50–34:39 | 填充顺序：进阶方式→频率→动作→顺序→强度/训练量→休息 | 作为编写单次课表的固定检查顺序 |
| 34:38–35:22 | 对新手“有效”不等于最优，也不等于为未来建基础 | 不用“反正新手做什么都涨”取代合理设计 |

## 为 Mia 场景做的二次设计

以下不应归因为 Galpin 在该视频中的逐条原话：

- 三色反馈和具体回调决策；
- 对 30+ 女性、忙碌普通人、减脂期和抗衰场景的默认优先级；
- 不按月经日历机械降训练、而按个人症状和表现调整的规则；
- 忙碌日最小版、替代动作、RPE/RIR 优先等可执行性设计；
- 对疼痛、孕产期、慢病、用药和急性症状的停止/转介规则。

对外解释时，可以说“这套方法以 Galpin 的大到小规划为骨架，再加入 Mia 人群需要的安全、执行与反馈规则”。

## 转录中已校正的主要词汇

- *periodization*：周期化
- *macrocycle / mesocycle / microcycle*：宏周期 / 中周期 / 微周期
- *hypertrophy*：肌肥大/增肌
- *functional overreaching*：功能性超量负荷
- *taper*：赛前减量
- *GPP*：通用身体准备
- *daily/weekly undulating periodization*：按日/按周波动周期化
- *vertical integration*：垂直整合
